## SHIPS in 0.2.0 (built, merged, tested)
- 13 premade bots, approvals (ask / auto-edits / full) and the taint model, rooms, the Library and Lattice, an optional cloud VM per agent through the user's own boat.dev account, MCP so Claude Code and Cowork can drive Legion.
- PROJECTS (new): group tasks, rooms, notes and agents per project; project instructions; owner-only control; notes can be scoped to a project; MCP gets read-only project tools.
- INSTALL: setup.cmd / setup-yes.cmd. NEW: a prebuilt package route that needs no Node, no Git and no npm (it carries Electron, which has Node built in, plus the Claude engine from the Agent SDK, about 270 MB zipped; built by a script, NOT yet built or run on Windows). The source route (git clone) stays, and can fetch Node itself, after asking. Installer is unsigned (SmartScreen may warn). Legion uses the user's existing Claude sign-in or an API key; a user does not need Claude Code installed for the package route.
- IN-APP UPDATER: checks GitHub releases, shows an Update panel, downloads only after the user clicks, installs only when Legion is idle, rolls back if the new version does not start, signed manifest. It is OFF until the owner publishes a signing key and the repo is public.
- SECURITY: the core listens on loopback only (Host, address and Origin checks before any route, a fixed listen address with a test); secrets scrubbing hardened.
- BSV MODE (off by default): read-only knowledge pack (163 notes, 727 links, pack version 8) and wallet status; THE SPEND TOOL IS BUILT (testnet and mainnet capability, mainnet hard-off behind a native-confirmed switch, an Arm and the wallet's own prompt) but only ever run against fake wallets: NOT verified with a real wallet or real funds. The title bar shows the real count of BSV notes in the user's graph and explains differences from the bundled pack.
- BLENDER: Sculptor agent. Default: headless Blender on this computer when Blender is found; cloud VM is the isolated option; live Blender through an add-on is the third. Settings can fetch ONE pinned official portable Blender (5.2.2 LTS, hash checked, after the user's approval) or link to blender.org/download. First-use chooser. Optional "use both add-on backends" (official Blender MCP main, community add-on second), off by default; asset downloads (Poly Haven) are done by Legion itself behind an approval card per download. None of it tried on a real Blender yet.
- BROWSER TOOL (new, optional, OFF by default): lets agents browse without a VM, using a headless Edge or Chrome that is already on the PC (no download, no WSL). IN PROGRESS: do NOT claim it as shipped until this file says so. Everything a page returns is treated as untrusted; runs become tainted; Legion refuses private addresses and never touches the BSV wallet port; asks before visiting a new site. HONEST LIMIT: a local browser runs with the user's rights; a cloud VM (boat.dev) is the only isolated way to browse. Lightpanda was evaluated and DROPPED (no native Windows build, extra layer): do not mention it. agent-browser may become an optional engine later: do not claim it.
- TEST HARNESS (a DEVELOPER tool in the source repo, NOT a product feature): stand-ins for the model, the wallet and Blender so contributors and AI agents can test Legion without any real service. Mention it once, in a 'for developers' place only. Legion itself works with REAL Blender, real wallets and real Claude.
