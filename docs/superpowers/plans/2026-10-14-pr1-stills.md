# PR 1: Stills at rest, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Every resting bust is a pre-rendered image; the live mascot engine mounts only on hover or keyboard focus (and on the stage) and is destroyed on leave; an awaiting bust has a static amber ring.

**Architecture:** `scripts/build-bust-stills.mjs` mounts the real engine with the real CSS in Edge and writes one WebP per bust x state x theme into `ui/src/mascot/stills/<theme>/`. A pure module (`stillsLogic.ts`) names files and maps pose to still; `stills.ts` (Vite) resolves URLs via `import.meta.glob`; `Bust.tsx` renders the image at rest and mounts the engine on wake.

**Tech Stack:** TypeScript, React, Vite IIFE bundle (file://), playwright-core + Edge for generation only (not a repo dependency).

**Spec:** `docs/superpowers/specs/2026-10-14-runs-without-you-design.md` sections 7, 10 "PR 1", 9.1 (bust-still).

## Global Constraints
- Stills budget 1.5 MB total; must load from `file://` inside the IIFE bundle.
- Stage (`BustStage`) and Mascot Lab keep live behaviour; `Bust` props unchanged.
- `mascot.css` first 10392 bytes and `Relic.tsx` are pinned by test/mascot.test.ts: append only.
- No em dashes, no outside product names, no Co-Authored-By.

## Review Focus
- A bust id with no still (custom agent, new bust) keeps today's live behaviour.
- Poses with no still (listening, victory, annoyed) show the idle still; hover still goes live in the right pose.
- Wake then leave before the art loads must not leave a live engine behind.
- Light theme: no dark aura disc on a light tile.
