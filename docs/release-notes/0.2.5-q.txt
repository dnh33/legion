Legion 0.2.5-q — the prebuilt package installs and runs.

- The prebuilt package now ships a working Electron binary and the required resources directory. Previously the package contained a corrupt binary and was missing a required file, so the app exited silently after installation.
- The renderer script loads correctly in the bundled package. The previous build produced a script tag that did not support ES modules; it now uses the module type so in-code imports work.
- Update relaunch no longer blanks the renderer. The single-instance lock is now skipped during the update relaunch so the new version starts cleanly.
- Dependency-changing updates install themselves on Windows. The installer's swap step ran from inside the directory it was replacing, which Windows refuses; the swap now runs from a separate runtime.
- The update panel reports the true download size for dependency updates and offers a one-click retry.
- A title-bar badge announces available updates and their progress.

Installs over 0.2.5-o and 0.2.5-p. Full detail in CHANGELOG.md.
