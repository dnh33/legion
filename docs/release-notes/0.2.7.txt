Restarting stops running agents. Each stopped run offers Continue afterwards. You need to do nothing.

Stop a whole team at once
When a task had started other tasks, stopping it left the others running, and their answers woke it again.
Now one click stops the task and everything it started: "Stop this and the 2 tasks it started".
Try it: open the task menu, or use Stop all next to Stop.

Also new:
- OpenAI, Ollama, LM Studio and vLLM are usable in Settings, Providers.
- Resting mascots are still pictures, so the agent list and pages move smoothly.
- An agent's task tabs follow the project you chose.
Fixed:
- An agent busy in one project no longer stops you starting a task in another.
- A tool call a model wrote as plain text is no longer shown as its answer.
- New installs no longer fail when antivirus removes a file Legion did not need.

Installs over 0.2.5-o and later. Full detail in CHANGELOG.md.
