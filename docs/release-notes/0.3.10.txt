This update installs from inside Legion.

Your agents are no longer stopped by what they read
Before, an agent that had read a web page, a GitHub comment or a file from outside your project could not assign or delete board items, write working memory or share notes directly. Now it carries on as normal. What it creates carries a label, and the next run is told when its working memory came from a run that read outside text. Money confirmations, GitHub write cards, the stop for disastrous commands and your Block rules work as before. A trigger tag an agent writes is saved like any note and never fires on its own; only a note you wrote or accepted yourself can fire.

Running a program never marks a run
node -e, make, go test, npx, npm install, git pull and programs Legion does not know leave an agent clean. Only text that comes in from outside marks a run: the web, GitHub text you read, other tools and files outside your project.

The board works the way you build
An item an agent wrote is routed by the Marshal like any other, and your Run button runs it as you set the agent up.

Agent chains run like your own runs
An agent that another agent started at full approval is no longer treated as limited. A run limited to Ask still asks.

You stay in control
A new choice, Never mark, switches labels off. It also removes the extras that depend on a label: the extra confirmation on payments and the warning on GitHub write cards. Your approval setting, Block rules and the stop for disastrous commands still apply.
Settings, Gates, Outside text, Strict keeps every lock from 0.3.9, marks every shell command and keeps the approval card for web access after a run read GitHub data and the old rule for runs another agent started. Nothing needs migrating.

Smaller fixes
After a good update, Settings, About shows one line with a Show steps button instead of the whole list. The GitHub area now says that each agent needs its own write access, and the refusal an agent gets says where to give it.

One thing to know
A test script that fetches a web page by itself does not get a label. In a repository you do not trust, choose Strict.
